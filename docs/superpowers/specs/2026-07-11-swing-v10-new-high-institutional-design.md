# 🎯 스윙 v10 설계 — 신고가 거감짜름 (KR 전시장·코스닥 포함)

## 1. 배경 · 목표

유튜브 영상(보컬 김영준, 실전투자대회 12회 수상)의 **신고가 상승음봉 매매 기법**을
v9 스윙 모델을 베이스로 코드화한다. 사용자 요구: **역사적 신고가 + 기관 수급**을
핵심으로 포함하고 **코스닥도 대상**에 넣는다.

### 영상 기법 요약 (4대 포인트)
1. **신고가 + 큰 거래량** — 평소 대비 2~3배 거래량으로 **장대 양봉**이 신고가 저항선 돌파.
   우선순위: 역사적 신고가 > 52주 신고가. (월봉 역사적 거래량이면 신고가 아니어도 "상방 관점")
2. **연속 수급** — 외국인보다 **기관**의 연속 순매수. 돌파 캔들에 기관 매수가 붙으면
   "기관이 이 자리에서 못 털고 나간다."
3. **시황** — 종목이 속한 섹터·시장의 동반 강세. (1·2 충족되면 대개 따라옴)
4. **명확한 타점** — 돌파 후 **첫 "거감짜름"(거래량 마르는 짧은 음봉)** 종가에 매수 →
   **5일선 이탈 시 매도**(손·익 무관). 장중매매 불필요(종가 대응, 대체거래소 오후 8시까지).

### v9와의 핵심 차이
- **진입이 다르다.** v9 = 20일선 눌림 반등 진입. v10 = **신고가 돌파 후 거감짜름(눌림) 진입.**
- **청산은 같다.** 둘 다 5일선 이탈까지 홀딩(추세추종). → 청산·리스크·하니스 프레임 재사용.

| 기관 수급 | **하드 게이트(백테스트)** + **라이브 페일오픈**(조회 실패 시 경고 후 허용) |
| 신고가 정의 | **티어드** — 52주(252일) 필수 + 전체이력 신고가면 가점 + 월봉 역사적 거래량 변형 |
| 아키텍처 | **접근법 A** — 전시장 패널 리플레이 + 후보만 수급조회 |

## 3. 아키텍처 — 접근법 A (2단계 필터)

전종목 수급조회(종목당 pykrx 추가콜 → 느림·실패율↑)를 피하기 위해,
**값싼 가격 셋업으로 먼저 후보를 좁힌 뒤, 후보에만 수급을 조회**한다.

```
1. 유니버스 : krx_universe.fetch_panel() → state/krx_panel.pkl
             (코스피+코스닥 보통주, 스팩 제외, ~420거래일)   ← 기존 인프라 재사용
2. 가격셋업 : 패널에서 벡터화 스캔(값쌈) → 후보 (종목, 돌파일 B, 거감짜름일 D)
3. 수급조회 : 후보에만 pykrx 기관 순매수 조회 → state/supply_cache/ 캐시
4. 수급게이트: 통과분만 진입
5. 청산     : v7 청산 재사용 (5일선 이탈 / 대량음봉 / 손절 / max_hold)
6. 검증     : harness / metrics / OOS 재사용 → v9와 A/B
```

## 4. 진입 판정식 (룩어헤드 없음 — 모두 종가 확정값)

종목 df 컬럼: open/high/low/close/volume, index=거래일.
보조지표: `ma5`(종가 5일), `va20`(거래량 20일 평균, 스파이크 계산 시 당일 제외), 전체/252일 rolling max.

### 4.1 돌파 캔들 B
| 조건 | 식 | 파라미터 |
|---|---|---|
| 52주 신고가 갱신 | `close[B] ≥ rolling_max(close, high_n)[B]` | `high_n=252` |
| 장대 양봉 | `close[B] > open[B]` AND `(close[B]−open[B])/open[B] ≥ body_min` | `body_min=0.03` |
| 거래량 급증 | `vol[B] ≥ vol_x × va20_prev[B]` | `vol_x=2.0` |
| 유동성 | `close[B]×vol[B]/1e8 ≥ min_tv_eok` | `min_tv_eok=50` |

가점·기록용 플래그(진입 판정 불변, 후보 랭킹 tiebreak/로깅에만):
- `all_time = close[B] ≥ rolling_max(close, 전체이력)[B]` (역사적 신고가)
- `hist_vol = vol[B] ≥ rolling_max(vol, 전체이력)[B] × 0.9` (역사적 거래량 근사 — 월봉 별도 파이프라인은 v1 제외, 전체 일봉 max로 근사)

### 4.2 거감짜름 D (돌파 후 첫 눌림)
B 다음 `window`봉 이내 **첫** 봉 j 중 다음을 모두 만족:
| 조건 | 식 | 파라미터 |
|---|---|---|
| 음봉 | `close[j] < open[j]` | — |
| 거래량 마름 | `vol[j] < va20[j]` AND `vol[j] < vol[B]×vol_dry` | `vol_dry=0.7` |
| 짧은 몸통 | `|close[j]−open[j]|/open[j] ≤ body_max` | `body_max=0.03` |
| 추세 유지 | `close[j] ≥ ma5[j]` (눌림이지 이탈 아님) | — |
| 탐색 창 | `j ∈ (B, B+window]` | `window=3` |

**진입 체결가 = `close[j]`** (종가 매수). 대체거래소 오후 8시 종가매수를
백테스트에선 당일 종가 체결로 근사. j일의 OHLCV는 종가에 모두 확정 → 룩어헤드 없음.
청산 루프는 `j+1`부터 시작.

## 5. 기관 수급 게이트 (④)

- 데이터 소스 결정 (2026-07-11 검증):

  - KRX_ID/KRX_PW가 .env에 있으면 pykrx 우선 시도(선택), 없으면 네이버 폴백.

- 실패 모드:
  - **백테스트(하드)**: 수급 조회 실패 → 그 거래 **드롭**(하드게이트 미검증 = 진입 안 함). `supply_required=true`.
  - **라이브(페일오픈)**: 조회 실패 → `수급 미확인` 경고 후 **진입 허용**.
- 캐시: `state/supply_cache/{ticker}.pkl`(또는 parquet). 증분·재사용. gitignore.

## 6. 시황 게이트 (⑤ · 소프트, config 토글, 기본 ON)

## 7. 청산 (⑥ · v7 재사용)

v9와 동일 프레임 — `_v7_exit` / `rules.decide_exit(mode="v7")` 재사용:
- **5일선 이탈**(`close<ma5`) or **대량거래량 음봉**(`vol≥va20×volspike`) or **손절 −3%**
  or **max_hold 백스톱** → 매도.
- `partial_exit_pct`(1차 익절 절반 + 잔량 트레일링)도 v9 설정 상속.
- 손절/익절/보유 파라미터는 기존 `risk.*` 재사용(신규 손절값 도입 안 함).

## 9. 데이터 흐름 · 에러 처리

- **패널 없음** → 명확한 에러(수집 안내). **synthetic 폴백을 성과로 쓰지 않는다**(no-guessing 원칙).
- **수급 조회 실패** → 백테스트: 거래 드롭 / 라이브: 페일오픈 경고.
- **pykrx rate limit** → 후보-only 조회 + 디스크 캐시로 완화, 재시도/백오프.
- **시황 데이터 실패** → 페일오픈.
- 비용: 기존 규약 재사용(`fee_bps`+`slip_bps` 왕복, 거래 1건당 1회).

## 10. 테스트 (TDD)

단위 테스트(합성/결정적 데이터):
- 거감짜름 검출 — 돌파+마름음봉을 심은 df에서 진입 index/체결가 정확 검증.
- 52주 신고가 판정 · `all_time`/`hist_vol` 플래그.
- 수급 게이트 — 3일 연속 순매수 유/무에 따른 통과·드롭.
- 시황 게이트 — 국면 상승/하락일 진입 허용/보류, 데이터 없음 페일오픈.
- **룩어헤드 없음** — 진입 판정이 ≤D 데이터만 사용(엄격 회귀).
- 비용 반영 · window 경계(3봉 내 없음 → 진입 없음).

통합/검증:
- `swing-v10-backtest` — 전시장 패널로 v10 거래 생성.
- **OOS A/B (v10 vs v9)** — walk-forward, `backtest.min_oos_trades` 표본 게이트, `oos_fraction=0.3`.
- synthetic 데이터는 성과 판정 금지(출처 표기).

## 12. 범위 밖 (YAGNI)

- 월봉 역사적 거래량 별도 파이프라인(전체 일봉 max로 근사).
- 돌파 "준비"(pre-breakout) 진입 케이스 — 영상은 post-breakout 거감짜름이 확률 높다 명시 → v1은 post만.
- 외국인 수급(영상은 기관 우선) — 로깅만, 게이트 아님.
- US 시장(수급 데이터 부재) — v10은 KR 전용.
- 라이브 3면 배선은 OOS 채택 전까지 보류.
