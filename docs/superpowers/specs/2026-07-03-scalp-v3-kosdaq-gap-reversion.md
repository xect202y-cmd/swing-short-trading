# 단타 v3 — 갭반등·코스닥 (검증 결과 + 구현 스펙)

날짜: 2026-07-03 · 상태: 검증 완료, 사용자 승인 후 구현
선행: `2026-07-03-scalp-daytrading-design.md`(v1/v2), 개선 실험 결과 아래

## 0. 왜 v3인가 (검증된 발견)

v1(변동성 돌파)·v2(갭반등)를 볼트 우량주 유니버스에서 돌리면 둘 다 엣지 없음
(정정 후 v1 -0.077%/PF 0.92, v2 -0.026%/PF 0.98). 개선 실험(2026-07-03, 500일 OOS):

- **(A) v2 우량주 파라미터 정교화**: 갭 구간·손절폭·거래량 조건 10변형 → 최선 PF 1.01. **엣지 없음**.
- **(B) 코스닥 유니버스 확장**: v1 돌파는 코스닥에서도 PF~1.0. 그러나
  **v2 갭반등 × 코스닥 = IS +0.075% / OOS +0.356% / PF 1.28 / 445+516거래**. ✅

### 견고성 검증 (과최적화 아님을 확인)
- **인접 파라미터 전부 양수**: 손절 -2.0~-3.5%, 갭 임계 -1.5~-2.5%, 거래대금 20~50억,
  추세필터 유무 → 9변형 모두 OOS PF 1.14~1.30. 매직 파라미터 의존 없음.
- **종목 분산**: 최대 기여 종목 23%, 40종목 분산. 요행 아님.
- **파라미터 미변경**(v2 기본 룰 그대로) + 유니버스만 교체 → 커브피팅 원천 불가.

### 정직한 리스크 — 레짐 의존 (반드시 인지)
- 시간 3분할: +0.40%(24.9~25.10) → **−0.37%**(25.10~26.03, PF 0.73) → +0.65%(26.03~26.07).
- 평균회귀의 본질: 변동·횡보장에서 벌고 추세하락·저변동장에서 몇 달씩 흘림.
- **결론**: 통계적 엣지는 실재하나 다개월 드로다운 존재 → 페이퍼로 실전 데이터 축적하며
  나중에 지수 레짐 필터를 A/B 검증(성급한 필터가 엣지를 죽일 수 있으므로 무필터 시작).

## 1. 모델 정의

**단타 v3 — 갭하락 과매도 반등 (코스닥 중소형)**
- 로직 = 기존 v2와 **동일한 체결 룰**(시가 갭하락 -2%↓ 진입, 손절 -2.5% 진입가앵커,
  당일 종가 청산). settle_item의 v2 경로 재사용.
- 차이 = **유니버스**: 볼트 우량주가 아니라 코스닥 중소형 큐레이트 리스트.
- 필터: 거래대금 하한 `scalp.v3_min_tv_eok`(기본 30억, 코스닥 현실 반영), 전일 20>60일선.

## 2b. 최종 결정 (2026-07-03, 추가 실험 후 확정)

추세/돌파 계열 재실험(N일고가돌파·갭업모멘텀·강한종가연속 × 우량주+코스닥):
전부 **IS 음수**(OOS만 +0.11은 레짐 요행) → 구조적 엣지 없음. v3(코스닥 갭반등)만이
IS·OOS 동시 양수. **결정: v1(돌파)·v2(우량주반등)를 라이브 페이퍼에서 은퇴,
v3 단일 라이브.** 죽은 모델에 페이퍼 자본 미배정. 2번째 모델은 계속 탐색(아키텍처는
N모델 확장 유지 — 찾으면 즉시 추가). v1/v2 백테스트 곡선은 대시보드에 **참고(폐기)**로
남겨 "왜 은퇴했는지" 근거 보존.

## 3. 구현 범위 (승인 후)

라이브 페이퍼 = v3 단일. v1/v2는 코드 유지하되 라이브 실행/계좌에서 제외:

1. **account.py**: 라이브 `_LIVE_MODELS = ("v3",)`, 시드 v3=300만. 기존 scalp_state.json의
   v1/v2 슬롯은 보존(마이그레이션 불요 — models dict에 v3 추가, 라이브 정산은 v3만).
2. **strategy.py**: settle_item 갭 경로를 `model in ("v2","v3")`로 라우팅(v3=v2 로직 재사용).
   k 불필요, 손절 -2.5% 진입가앵커 동일.
3. **planner.py**: 코스닥 유니버스 로더(config `scalp.kosdaq_universe` 40종목) 신규.
   v3 후보를 코스닥에서 로드(볼트 아님). 시나리오/그림자 A/B 동일 적용.
4. **main.run_scalp**: KR 런에서 v3 처리(코스닥=한국장). US 런은 v3 대상 아님(코스닥 미개장).
   v1/v2 계획/정산 호출 제거(라이브 은퇴) — 단, 함수/테스트는 유지(백테스트가 사용).
5. **backtest.py + run_scalp_compare**: v3(갭반등·코스닥) 리플레이 추가. scalp_compare.json
   versions = [v1, v2, v3](v1/v2는 "폐기" 라벨). 대시보드 versions 동적이라 자동 노출.
6. **briefer.py**: v3 결과/계획 라인(⚡ 임베드). v1/v2 섹션은 라이브 미발생이라 자연 생략.
7. **대시보드**: 성과탭 10만원 카드의 단타 행 = v3 기준(seedTotal 300만 단일). compareCategories
   scalp seed 라벨 300만 유지.

## 4. 검증 계획

- 단위테스트: v3 갭 라우팅(settle_item model="v3" = v2 로직), 코스닥 로더, account v3 정산.
- `scalp-compare` → scalp_compare.json에 v3 항목, OOS PF>1.05 재확인(라이브 데이터로).
- 페이퍼 1사이클: v3 계획(코스닥 갭하락 후보) 디스코드 노출 확인.
- 대시보드: 비교화면 단타 카테고리에 v3(+참고 v1/v2) 노출, 10만원 카드 단타 행 v3.

## 5. 범위 밖 / 후속

- 지수 레짐 필터(무필터로 시작, 페이퍼 데이터 축적 후 A/B) — 성급 적용 금지.
- **2번째 모델 탐색(진행형)**: 추세/돌파 전부 IS 음수로 탈락(N일고가·갭업·강한종가).
  다음 후보=반등 유니버스 확장(150~200 코스닥), 인트라데이 급락 반등(분봉 필요),
  또는 완전 신규 로직. v3와 다른 성격이거나 최소 IS·OOS 동시 양수여야 채택.
- 코스닥 v1 돌파(PF~1.0)·우량주 v2 정교화(PF 1.01)·모멘텀 계열(IS 음수) — 전부 미채택.
